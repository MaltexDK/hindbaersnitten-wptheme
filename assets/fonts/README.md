# Local fonts

Fraunces and Manrope from https://github.com/google/fonts/tree/main/ofl,
licensed under SIL OFL 1.1; licenses are included beside the fonts.
WOFF2 files retain the complete upstream character sets, including Danish.
Fraunces retains all axes; the theme uses SOFT 50 and WONK 1 in CSS.
Manrope retains its weight axis. Fonts use font-display: swap via theme.json.
No third-party font requests are made by this theme.
